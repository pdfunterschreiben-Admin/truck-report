# Truck Report

Truck Reports aus T-Doc speichern (TruckCom-Format), zwei Reports vergleichen und das Fehlerprotokoll auswerten.

**Download:** [TruckReport-Setup.exe](https://github.com/pdfunterschreiben-Admin/truck-report/raw/main/TruckReport-Setup.exe)

Setup starten → „Ja“ → das Programm installiert sich für den eigenen Benutzer (ohne Administratorrechte) und legt eine Verknüpfung auf dem Desktop an.
Neue Versionen installiert das Programm beim Start automatisch.

Aktuelle Version: siehe `version.json`.
