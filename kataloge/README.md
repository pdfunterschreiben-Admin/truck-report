# Gemeinsame Kataloge

Diese Dateien holt sich jedes Truck-Report-Programm beim Start. Eigene Einträge eines Kollegen haben Vorrang.

| Datei | Spalten |
|---|---|
| Fehlercodes.csv | Code; Beschreibung; Hinweis |
| Messwerte.csv | Nr; Bezeichnung; Einheit; Faktor |
| Parameter.csv | Nr; Bezeichnung; Einheit (ab 1200 = Hydraulik-Kalibrierung) |
| Sollwerte.csv | Kunde oder Modell; Parameter; Sollwert; Hinweis |

Semikolon-getrennt, UTF-8 – lässt sich in Excel öffnen und speichern („CSV UTF-8“).
